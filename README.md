# Wanted Optimizer Pro

Free all-in-one Windows 10/11 optimizer for gamers and power users.

## Features
- **100+ tweaks** for System Tuning, Performance, Hardware, Network and Privacy & Security. Each one reads the real Windows state, applies, confirms, and can be undone.
- **Gaming Mode**: build one gaming profile, switch it on or off from the title bar, and restore exactly what it changed.
- **Live Dashboard**: CPU, memory, disk and network performance with a chart and recommendations.
- **RAM Cleaner**: clean manually or automatically at a memory level you choose.
- **PC Cleaner** and **Restore Points**.
- **Startup cleanup**: removes broken startup entries, with a backup you can restore.
- **Hardware detection**: AMD and NVIDIA controls show only when your hardware is found.
- **Undo / Restore Defaults** for every change.
- **Update Center**: checks GitHub for new versions, verifies and installs them.
- **English and Arabic** with full right-to-left layout.
- Dark interface, tray icon, scales to any screen size and display scaling.
